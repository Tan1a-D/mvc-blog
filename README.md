# Мой блог — экшн sayBye
Самостоятельная работа по основам серверной веб-разработки. Доненко Татьяна Александровна, группа 253-325.

Проект собран по предоставленным HTML и CSS блога, так как исходный контроллер и роутер не предоставлены. Это самостоятельная минимальная реализация MVC, а не правка неизвестного фреймворка. База данных для задания не нужна.

## Экшн и маршрут
`MainController::sayBye(string $name)` передаёт имя в шаблон bye.php. Шаблон выводит «Пока, $name» и экранирует HTML. index.php сопоставляет путь `/bye/([^/]+)` с действием sayBye. Имя декодируется через rawurldecode, поддерживается кириллица и пробелы. Пустое имя не соответствует маршруту; неверная кодировка, управляющие символы и закодированный разделитель пути отклоняются.

## Запуск
PHP 8.1+:
```sh
php -S 127.0.0.1:8082 router.php
```
Открыть http://127.0.0.1:8082/bye/Татьяна — в основном блоке должно появиться «Пока, Татьяна».

## InfinityFree
Создать отдельную папку htdocs/mvc-blog и загрузить туда index.php, .htaccess и папки src, templates, styles. Включить показ скрытых файлов при загрузке .htaccess. router.php нужен только для локального сервера, на хостинг его загружать не надо.
Проверить https://tania-feedback.rf.gd/mvc-blog/bye/Татьяна. Префикс /mvc-blog относится к папке размещения; маршрут приложения — /bye/$name. В корне отдельного домена он будет иметь вид https://DOMAIN/bye/NAME.
Прежние работы в htdocs и htdocs/contacts не изменять.

## Файлы
- index.php — маршруты и запуск контроллера.
- src/Controllers/MainController.php — действия и подключение шаблонов.
- templates/layout.php — общий макет из задания.
- templates/bye.php — вывод приветствия «Пока».
- templates/home.php и about.php — главная и страница автора.
- styles/styles.css — оформление на основе предоставленного CSS; исправлен селектор .layout.
- .htaccess — перенаправление человекочитаемых URL на index.php.

## Заголовки страниц и приветствие
Метод render принимает имя шаблона и массив переменных. Ключ title задаёт заголовок вкладки через переменную $title в templates/layout.php. Если title отсутствует, шаблон выводит «Мой блог». Главная страница вызывает render без title и демонстрирует значение по умолчанию.

Экшн sayHello(string $name) обрабатывает /hello/$name и передаёт title «Страница приветствия». Проверка: https://tania-feedback.rf.gd/mvc-blog/hello/username. Вкладка должна называться «Страница приветствия», содержимое — «Привет, username».
